PocketMesh 3D · Support

Make a little world.

A compact 3D modeling studio for game props and ideas on the go.

Create low-poly models, generate editable props, try object animation and physics, then export static meshes to your next project.

Need a hand?

Email cogankaa@gmail.com. Include your device, iOS version, PocketMesh 3D version, and steps to reproduce the issue. Attach a project only if you are comfortable sharing it.

Start creating

  1. Open Procedural, choose a category and style, then adjust the controls.
  2. Tap Convert to mesh & add. Use Model to edit faces and vertices.
  3. Hold an object and choose Remove from scene to delete it. Undo restores it.
  4. Use the project menu to export GLB, OBJ with materials/textures, or an editable project.

Where is my work saved?

Completed edits save automatically on your device. Opening a demo or another project creates a recovery copy. Find these in Objects & scenes → Recovered scenes. Export an editable project to Files for a separate backup before deleting the app.

Can my device scan objects?

Live capture requires a device supported by Apple Object Capture, including the necessary LiDAR hardware. It is unavailable on the standard iPhone 16. The app checks support before offering capture. You can open a compatible USDZ scan on other devices.

What can I export?

GLB exports static mesh, basic PBR materials and scan textures. OBJ exports geometry with MTL and any scan JPEG files; keep those files together. Custom animated water shading, physics rules and animation are not exported in these static formats. The editable project retains PocketMesh 3D scene data. OBJ/GLB import, rigging and texture painting are not included in version 1.0.

Large files

Use Compact scan quality for smaller textures. Split large scenes into separate projects. Import and export have memory and geometry limits; detailed scans may be rejected instead of being added. Performance depends on device and scene complexity.
